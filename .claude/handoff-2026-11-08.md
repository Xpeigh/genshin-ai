## Non-obvious decisions
1. **`net/` is a package outside the SPEC module list**, because the spec demands one HTTP client module; `paths.py`/`config.py` are shared leaf helpers exempt from the dependency-direction test.
2. **The allowlist lives in code (`config.py`)**, not in a user-editable or downloadable file, so downloaded data and user files can never widen it.
3. **Redirects are followed by our code, not httpx**, so every hop is re-validated. `trust_env=False` ignores proxy/netrc environment variables.
4. **Windows has no `make`**: `tasks.py` is the task runner; `uv` is installed via `pip --user` and also listed as a dev dependency.
5. **Fixtures are synthetic.** Upstream files are unlicensed, so no real data is committed; `tests/test_real_data_smoke.py` runs only when `GENSHIN_REAL_DATA_DIR` points at local copies.
6. **Confidence semantics**: `curated` = two independent sources agree; `provisional` = single source or any disagreement; `verified` is never set automatically (reserved for Ben's hand-checked golden fixtures). Confidence is per dataset for now.
7. **Affix ids are not decoded beyond the rarity digit and position digit.** Real data showed the middle two digits are not the PropType (elemental mastery differs), so only `<rarity>01..<position>` is used and the Amber cross-check backs the rarity assumption.
8. **Level keys are one-based** upstream (`"1"` = +0); we store zero-based levels. Float32 noise (`138.9` vs `138.89999`) is tolerated by relative comparison.
9. **Pinned vs latest**: the Enka commit is pinned in `data/sources.py` (resolved with `git ls-remote` because the unauthenticated GitHub API is limited to 60 requests/hour); `--latest` is an explicit opt-in recorded as unpinned.
10. **Sync is conservative**: a missing cross-check source fails the sync unless `--allow-single-source`; changed roll values or large removals are `held` in quarantine until `--accept-held`.
11. **The HTTP client requests `Accept-Encoding: identity` and refuses any compressed response** instead of decoding it. A red-team review showed httpx decodes whole bursts into memory before a decoded-size cap can fire (decompression bomb). Wire bytes are capped per network read (`iter_raw`); the total deadline is checked every read and each read's timeout is clamped to the time remaining.
12. **Client errors are raised outside `except` blocks** with no `__cause__`/`__context__`, so a traceback written by a caller's `logger.exception()` cannot contain the URL (it holds the UID). httpx/httpcore loggers get a filter re-asserted on every client construction.
13. **Static architecture tests are tripwires, not a sandbox** (red-teamed 2026-11-08). They now resolve relative imports, reject star imports and re-exported network names, parse bytes (PEP 263 cookies), fail on unscanned file types, require every new package to get rules, and check transitive reach for `scoring` and `chat`. `asyncio`, `uvicorn` and `fastapi` are in the banned network list, so the Phase 4b local API server module needs one narrowly scoped exemption.
14. **URL-parsing red-team round (done):** 190k fuzzed URLs/redirects produced zero allowlist violations. Fixed the low findings: numeric-looking allowlist entries (`127.1`, `0x7f.1`) are rejected, `NetworkPolicy` keeps an immutable copy of the allowlist, URL-parse errors no longer chain authority text, empty `host:` port is refused. Left as-is (fail-closed, documented): a malformed redirect `Location` that httpx rejects surfaces as `NetworkError` instead of `RedirectNotAllowedError`.
15. Test mocks go through `tests/helpers.StreamingTransport` so responses behave like real unread streams.
15. Stat values are stored as upstream gives them (percentages as fractions: `0.0583`), not as the percent numbers in SPEC.md hints.
