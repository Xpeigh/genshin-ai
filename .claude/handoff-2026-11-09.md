## Non-obvious decisions
1. **Ceiling, not forecast.** The game's upgrade odds are not in our data, so v1 gives only a floor and a best case, always labelled as such.
2. **Forced activation.** A piece showing fewer than four substats must spend its next upgrades unlocking new ones, so a +8 piece with one substat gets no extra ceiling (real pieces never look like that; the model follows the rule).
3. **Max levels live in a curated data file with provenance**, not in code: our main-stat table lists levels 0-20 for every rarity and cannot tell them.
4. **"Remember my UID" is the saved rosters**, so no extra personal-data file exists; `clear-data` already removes them.
